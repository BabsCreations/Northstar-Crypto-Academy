# Northstar Crypto Academy

A responsive, single-page educational website built with semantic HTML, CSS, and vanilla JavaScript. It has no backend, build step, API integration, or package dependencies.

## Preview locally

Open `index.html` directly in a modern browser, or serve this directory with any static file server. For example, with Python installed:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

The project can be deployed as a static site. Replace the temporary brand name and review the educational disclaimer for the client's needs before launch.

## Files

- `index.html` — page content, metadata, and semantic structure
- `style.css` — responsive layout, visual design, and reduced-motion handling
- `script.js` — mobile navigation, progressive reveal, and footer year
- `assets/` — reserved for any future local assets; current visuals are inline SVG and CSS

## Notes

The hero graphic is an illustrative learning framework, not live or historical market data. Fonts are requested from Google Fonts, with local system fallbacks if that service is unavailable.
